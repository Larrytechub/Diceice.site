# Chart Features and Capabilities

## Canvas Rendering
The `html2canvas-7375f9.smartcharts.js` file provides advanced HTML-to-canvas rendering capabilities including:

- SVG support
- Canvas element cloning
- Image rendering
- Custom element handling
- Transform and effects support

## Display Properties

### Supported Display Types
- Block
- Inline
- Inline-Block
- Flex
- Grid
- Table
- Ruby
- Contents

### Box Model Support
- Border radius (all corners)
- Border styles (solid, dashed, dotted, double)
- Padding control
- Margin handling
- Overflow management

## Background Handling

### Background Properties
- Color support (transparent, CSS colors)
- Image backgrounds (local and remote)
- Background positioning
- Background sizing (cover, contain, custom dimensions)
- Repeat patterns
- Gradient support (linear, radial)

### Supported Gradient Types
- Linear gradients with angle control
- Radial gradients with positioning
- Conic gradients
- Stop position management

## Text Rendering

### Text Features
- Font family selection
- Font size control
- Font weight (normal, bold, custom)
- Font style (normal, italic, oblique)
- Text transform (uppercase, lowercase, capitalize)
- Letter spacing
- Text shadow
- Text decoration (underline, overline, line-through)
- Text alignment

## Effects and Transforms

### Supported Effects
- Opacity control
- Transform matrix operations
- Rotation
- Scaling
- Skewing
- Translation

### Clipping
- Clip paths
- Border box clipping
- Padding box clipping
- Content box clipping

## Visual Enhancements

### Borders
- Width customization
- Color selection
- Style selection
- Individual corner radius
- Double border support

### Shadows
- Box shadows (multiple)
- Text shadows
- Shadow blur and spread
- Shadow color and opacity

### Color Support
Comprehensive color support including:
- Named colors (X11, CSS3 standard)
- RGB/RGBA values
- HEX notation
- HSL/HSLA values
- Keyword values (transparent, currentcolor)
